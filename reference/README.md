# Reference material (kept out of git)

Everything in this folder except this file is ignored by git, so it never reaches the public
repository or the GitHub Pages site.

- `manual/` — put the workshop manual PDF here (Haynes manual no. 572, CD/CM185 & 200T). It is a
  copyrighted book and this copy has a third party's name and phone number on every page, so it must
  stay private.
- `photos/` — the owner's photos of the bike. `set1-*` are the first four photos (5 Oct 2026);
  `set2-*` are the fourteen photos sent on 9 Oct 2026. `set2-01` and `set2-03` are the two left-side
  photos used for the measurements in `docs/measurements.md`.

Add new photos with a set prefix and a short description in this file, for example
`set3-01-front-hub.jpg`.
